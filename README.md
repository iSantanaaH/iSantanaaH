### 🚀 About Me

I'm a **Senior Fullstack Software Engineer** with around **6 years of experience** specializing in designing and building resilient, high-throughput distributed systems, cloud-native microservices, and enterprise web platforms.

- 🎓 **Education:** Technologist Degree in Systems Analysis and Development (UNOPAR).
